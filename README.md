# BUS4498 Team Build: Club Event Request Agent

## Team Charter (DRAFT - replace with your team's real charter)

**Problem:** Student club officers submit event funding requests by email and chat. The faculty advisor must check each one for missing details and budget problems, which takes days and causes late approvals.

**Goal:** Reduce the time from request to decision to under 2 business days by automating completeness checks and first-pass budget review, while keeping approval with a human.

**Users:** Club officers (requesters) and the faculty advisor (approver).

**Trigger:** A club officer submits the Event Request Form.

**Completion condition:** The requester receives an approval or denial notice that includes reasons.

**Out of scope:** Paying out funds, booking venues, and changing club policy.
